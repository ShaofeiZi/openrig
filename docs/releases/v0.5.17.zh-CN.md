# zrig v0.5.17 — 使用 Bun 安装

版本 **0.5.17** 的变更。Publication 状态与日期记录在 [GitHub release](https://github.com/mvschwarz/openrig/releases/tag/v0.5.17) 和 npm 中。

zrig 0.5.17 除 npm 外，也可以使用 Bun 安装。

## 使用 Bun 安装

```sh
bun add -g @openrig/cli
```

早期版本将未发布的 `@openrig/daemon` package 列为 dependency。npm 使用 package 内 bundled 副本，但 Bun 会到 registry 查询并返回 404。Package 现在直接导入已经随包发布的后台服务副本，不再依赖 `@openrig/daemon`，因此体积也更小。npm 安装行为不变。

zrig 仍运行于 Node.js，因此还需要安装 Node.js 22。Bun 可能阻止此 package 的 postinstall script；这种情况下，安装时不会运行 Node.js version 与 SQLite 检查。参见 [zrig 会对你的机器做出哪些变更](../../README.md#what-openrig-changes-on-your-machine)。

安装修复已在 macOS arm64、Node.js 22 环境中使用 Bun 1.4.0 和 npm 验证。其他组合尚未验证。

## 贡献者与包含的 Pull Request

感谢 [@drewpayment](https://github.com/drewpayment) 在 [#66](https://github.com/mvschwarz/openrig/issues/66) 中报告 Bun 安装失败；修复见 [#68](https://github.com/mvschwarz/openrig/pull/68)。

Node 支持范围和 SQLite 版本不变。0.5.15 记录的 macOS arm64 + Node 24 SQLite 安装限制仍适用；目前请在 macOS arm64 上使用 Node 22。
