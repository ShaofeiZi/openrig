# zrig v0.4.4

## 摘要 — 多主机与 Living Notes

zrig v0.4.4 交付多主机基础：共享工作组拓扑现在可以跨越多台主机，并支持分阶段启动、真实跨主机文件移动，以及合并拓扑内所有主机信号的统一 For-You activity feed。VPS product factory 场景也针对真实多主机操作得到强化。

除多主机基础外，本版本还发布 **Living Notes 信号层**：由智能体创作、可持久保存的 notes 界面，沿任务目标树串联 INTENT → PLAN → DELIVERED。单结构 review 契约从左到右呈现为一个垂直 stack：INTENT 在上、PLAN 居中、DELIVERED 在下；计划变化时删除旧计划，而非降级或堆叠。Composer 界面降低创作成本，review 界面则让意图与实现的对照一目了然。

运维 UX 新增 **`zrig ps` 统一默认视图**，使 token efficient defaults 系列获得 progressive disclosure；默认视图易于快速浏览，又不会隐藏 fleet。另有智能体工作高度协调 panel，在正确高度显示多智能体状态；以及 operationalize SDLC control plane，将发布、交付和生命周期控制集中到一个界面。As-built 文档也完成同步收尾。

如有 migration，均为叠加式。现有 v0.4.3 数据库可通过在新后台服务上运行 `zrig daemon start` 升级。

## 已发布内容

### 多主机基础

- **可共享的全拓扑分阶段启动** — 工作组拓扑可以跨多台主机分阶段启动；spec 与后台服务协同，使整个 fleet 达到绿色状态，无需先在单一主机完整启动。此前，全拓扑启动假定只有一台主机。
- **VPS product factory 多主机强化** — 已发布的 `openrig-user`/`openrig-architect` 运维流程可在 VPS/自托管 product factory 场景中正确工作；多主机 handshake 与 registration 得到强化。
- **多主机统一 For-You feed** — For-You feed 聚合拓扑中所有已注册主机的 activity，而不仅是本地后台服务。0.4.3 的 stream classifier 与真实数据保真会按主机应用，并在上游合并。真实主机 feed subscription capture 作为双重保险证明发布，详见“已知后续事项”。
- **`zrig file` 跨主机移动** — 文件可通过 `zrig file` 界面在拓扑中的已注册主机之间移动。在已合并的 VM stand-in 基础上，真实已注册双主机端到端 round trip 证明了该流程。

### Living Notes

- **信号层** — 任务目标和 slice 高度均提供持久化、由智能体创作的 notes 界面；INTENT / PLAN / DELIVERED 条目沿任务目标树传递，并带智能体作者与时间戳。
- **Composer 界面** — 低成本创作界面使 Living Notes 成为智能体记录决策、计划与已交付工作的首选位置。
- **单结构 review 契约（§3.1）— 修正重建** — Living Notes review 界面从左到右读取为**单个垂直 stack**：INTENT 在上，PLAN 与 mockup 居中，DELIVERED 与配对 proof 在下。计划变更时会**删除**旧计划并写入新计划，绝不降级或堆叠多个相互竞争的计划。人工 review 后，此修正重建取代了早期三栏布局。

### 运维 UX

- **`zrig ps` 统一默认视图 + progressive disclosure** — 默认 `zrig ps` 将 fleet 中可读的行统一成一个一眼可读的默认视图；通过 `--full` / `-A` / 逐 scope filter 进行 progressive disclosure，仍可获取丰富的逐节点记录。它延续 0.4.0 建立的 token efficient defaults 系列。
- **智能体工作高度协调 panel** — 协调界面根据正确高度（工作区 / 任务目标 / slice）限定 scope，使运维人员无需淹没在逐席位细节中也能看到真实协调状态。它与 0.4.1 发布的工作区可观测性 tab 组合使用。

### 工作原则

- **Operationalize SDLC control plane** — 发布、交付和生命周期控制集中到单一界面。0.4.1 → 0.4.3 已发布 lane（release cut squash + bounded diff、sidecar operator host cutover、curation pass）现在成为一等 control plane 操作，不再只是生命周期口耳相传的知识。
- **As-built 文档收尾** — as-built 文档系列（`docs/as-built/architecture.md`、`docs/as-built/cli-reference.md`、codemap）已同步到 0.4.4 实际发布状态。

## 行为与兼容性

- **Migration** — 仅叠加。现有 v0.4.3 数据库可通过在新后台服务上运行 `zrig daemon start` 升级。
- **多主机 registration** — 多主机 handshake 与单主机部署向后兼容；单主机操作不变。
- **`zrig ps` 默认视图** — 统一默认值是紧凑、可读的视图；`--full` 返回 v0.4.3 的默认结构。
- **For-You feed** — 只有加入 registered host membership 才会启用多主机 feed aggregation；单主机拓扑行为不变。
