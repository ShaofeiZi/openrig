# zrig v0.5.7 — 弹性拓扑与一致的工作投递

zrig 0.5.7 使运行中拓扑更容易创建和调整，无需手工创作 YAML；同时为智能体提供一致、可寻址的工作安装，使其能够正确接入正在参与的工作。

## 弹性拓扑生命周期

- **无需 YAML 即可创建。** 可以只通过公开 CLI 输入启动工作组，无需先编写 RigSpec。
- **原位扩展拓扑。** 向现有 pod 添加一个或多个成员，或创建并填充新 pod；混合结果会如实报告。
- **保持声明忠实。** Spec show/export 会保留拓扑，包括成员声明的 agent image source，因此 save 后重新创建不会静默改变该成员的启动方式。
- **安全收缩。** 目标持有活跃工作时拒绝移除。显式 drain fallback 会保留 queue item identity 和 state，验证 fallback session 为 live，并且只移除预期席位或 pod。无工作的常规清理仍可直接执行。

## 一致的工作投递

- **可组合的 Product Journey SDLC。** 已发布工作模型组合 world、project、mission 和 slice context，不要求一份单体 briefing。
- **实用的 Work Install 默认值。** 全新 project、mission 和 slice scaffold 提供符合约定的 Markdown 与 manifest 文件，不覆盖作者内容。
- **可选 YAML 增强。** Project manifest 可增加作者创作的 intent 和有序 context address。无效可选值会明确警告，并保留安全的默认安装。
- **可寻址 Markdown 加载。** 已安装技能可以按相对地址解析精确 Markdown 章节，包括通过常规 symlink plugin projection 访问。
- **显式 Project Identity。** 智能体可以选择和切换 project，而不跨 root 携带上下文；ambiguous、duplicate 和 unknown identity 会拒绝，不会猜测。
- **完整的仅插件公开技能目录。** 每个只由插件提供、已收入目录的公开技能，都会连同其指令引用的 helper file 一起投影。
