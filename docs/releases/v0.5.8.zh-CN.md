# zrig v0.5.8 — 可恢复的运维与可见工作

zrig 0.5.8 使长期运行的工作组更容易恢复、理解和操作。本版本增加突发故障后的精确选定工作组恢复，使当前任务目标及其执行过程同时对智能体和运维人员可见，并收紧用于保持 live state 真实的诊断与 guardrail。

## 恢复与拓扑生命周期

- **故障后恢复选定工作组。** Restore 现在会拒绝过期 native identity，使用真实 provider session 证据，并避免换入全新或错误 occupant，也不会启动无关 sibling 工作组。
- **使用统一拓扑创建路径。** 公开 create 与 grow 会收敛到相同后台服务 effect，同时保留成员 working directory override。
- **保持拓扑声明可用。** 工作组公开真实的自描述，工作区声明在 export 后仍保留；经过验证的工作区声明可以应用到现有工作组，且不改变其拓扑。

## 任务目标与上下文可见性

- **从 SCOPES 打开任务目标执行过程。** 选中的任务目标现在会显示可读的 `DONE` / `NOW` / `NEXT` / `ATTENTION` 过程，真实的 working lane 和 evidence gap 数量、有界 overflow，以及稳定的任务目标切换。
- **安装真正处于当前状态的工作。** Work install 能解析完整文件和 dot form slice ID；refocus 会派生席位 typed 当前任务目标与 slice，而不是要求智能体从记忆重建。
- **发现已发布能力。** 可以通过已安装 context route 访问公开 capability world 及其可寻址上下文。

## 运维真实性与更安全的初始化

- **只为需要关注的状态唤醒一次。** Park timer 会在每条退出路径上退休；新 park episode 会取代旧 timer；idle gate watchdog 使用与系统其余部分相同的仲裁 activity oracle。
- **诊断真正存活的机制。** Producer link health 从 effective endpoint 派生，topology freshness 有界，synthetic model record 不再产生虚假 model divergence finding。
- **保留用户拥有的 Codex 配置。** Managed TOML projection 在写入前拒绝 malformed 或 root scoped fragment；合法冲突时保留用户 table。
- **保持升级由智能体主导。** 已发布 upgrade skill 提供有界检查、已验证数据库备份和受控 managed plugin refresh helper，同时将 cutover 判断留给负责运维的智能体。
- **信任 clean checkout 结果。** 文档中的后台服务测试 gate 与 same SHA long lived gate 现在基于同一确定性源码真相。

## 运维 / 初始化说明

- Root、CLI、后台服务和 Web UI package version 前进到 `0.5.8`；终端 TUI 保持独立版本 `0.1.0`。
- 数据库 migration head 从 `077_node_session_source` 前进到 `078_idle_gate_fired_condition`；后台服务正常启动时自动应用，无需手工迁移。
- 现有工作组无需重写拓扑。新的 workspace only apply 路径有意不修改 member、pod、edge 和 running session。

## 已知限制

- 选定工作组恢复不覆盖数据库与文件系统同时完全丢失，也不覆盖 fleet wide 自动重启。
- 现有工作组的 workspace 流程不验证 `target_repo`；该独立问题不在本版本契约内。
- 既有后端 `attention_required` 状态不属于有界 TUI topology freshness 工作。

## 发布验证

- 独立 QA 与 review 在 110 列和 160 列下演练最终 SCOPES 执行 journey，包括任务目标选择、可读 evidence gap、有界 overflow、slice drill in 和 Escape navigation。
- 恢复测试使用真实 Claude 与 Codex occupant，覆盖 current、stale、absent 和 insufficient evidence 状态；还覆盖同一 zrig occupant record 内 native session identity 发生变化的情况。
- 已接受产品 tree 以 0.5.7 为根重放为线性公开 lineage。每位 author 和 committer 均使用项目 noreply identity，重放后的产品 tree 与已接受 local main tree 逐字节一致。
- Release acceptance 包括 package assembly、hash bound 逐文件 substance review，以及针对精确 private cut 的 installed runtime QA 与 review。
