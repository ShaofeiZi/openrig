# 问题分类

用于分类 dogfood 测试期间发现的问题。在每次 dogfood 会话开始时阅读本文，校准需要关注的问题。

## 内容

- [Severity Levels](#severity-levels)
- [Categories](#categories)
- [Exploration Checklist](#exploration-checklist)

## 严重级别

| 严重程度 | 定义 |
|----------|------------|
| **critical** | 阻断核心工作流、导致数据丢失或使应用崩溃 |
| **high** | 主要功能损坏或不可用，且没有变通方法 |
| **medium** | 功能仍能运行，但问题明显，存在变通方法 |
| **low** | 轻微的外观或打磨问题 |

## 类别

### 视觉/UI

- 布局损坏或未对齐的元素
- 重叠或剪切的文本
- 间距、填充或边距不一致
- 图标/图像丢失或损坏
- 深色模式/浅色模式渲染问题
- 响应式布局问题（视口大小）
- Z-index 堆叠问题（元素隐藏在其他元素后面）
- 字体渲染问题（错误的字体、大小、粗细）
- 色彩对比度问题
- 动画故障或卡顿

### 功能性

- 链接损坏（404，目的地错误）
- 单击时不执行任何操作的按钮或控件
- 表单验证拒绝有效输入或接受无效输入
- 重定向错误
- 默默失败的功能
- 状态未按预期保留（刷新、导航时丢失）
- 竞争条件（双重提交、陈旧数据）
- 搜索或过滤损坏
- 分页问题
- 文件上传/下载失败

### UX

- 混乱或不清楚的导航
- 缺少加载指示器或操作后的反馈
- 交互缓慢或无响应（>300 毫秒感知延迟）
- 不清楚的错误信息
- 缺少对破坏性行为的确认
- 死胡同（无法返回或继续）
- 相似特征之间的模式不一致
- 缺少键盘快捷键或焦点管理
- 不直观的默认值
- 缺少空状态或无用的空状态

### 内容

- 拼写错误或语法错误
- 过时或不正确的文本
- 留下的占位符或 lorem ipsum 内容
- 截断文本，没有工具提示或扩展
- 标签缺失或错误
- 术语不一致

### 性能

- 页面加载速度慢（>3秒）
- 滚动或动画卡顿
- 布局变化较大（内容跳跃）
- 网络请求过多（通过控制台/网络检查）
- 内存泄漏（页面随着时间的推移变慢）
- 未优化的图像（文件大小较大）

### 控制台/错误

- 控制台中的 JavaScript 异常
- 失败的网络请求（4xx、5xx）
- 弃用警告
- CORS错误
- 混合内容警告
- 未处理的 Promise rejection

### 无障碍

- 图像上缺少替代文本
- 未标记的表单输入
- 键盘导航不佳（无法使用 Tab 键导航到元素）
- 焦点陷阱
- 色彩对比度不足
- 动态内容缺少 ARIA 属性
- 屏幕阅读器不兼容的模式

## 探索清单

将此作为在每个页面/功能上测试内容的指南：

1. **视觉扫描** -- 截取带注释的屏幕截图。查找布局、对齐和渲染问题。
2. **交互式元素** -- 单击每个按钮、链接和控件。它们有效吗？有反馈吗？
3. **表单** -- 填写并提交。测试空提交、无效输入和边界情况。
4. **导航** -- 走遍所有导航路径。检查面包屑、后退按钮和深链接。
5. **状态** -- 检查空状态、加载状态、错误状态和满/溢出状态。
6. **控制台** -- 检查 JS 错误、失败的请求和警告。
7. **响应性** - 如果相关，请在不同的视口大小下进行测试。
8. **身份验证边界** -- 测试未登录时会发生什么，如果适用，使用不同的角色。
