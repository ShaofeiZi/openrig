# 项目树完整示例（demo）

此文件夹是项目树链式文件的**完整示例**——这是本工作组还会随拓扑默认值交付的另一棵树。请复制其结构，而不是内容。

**直白地说，为什么项目上下文不能作为默认值交付：**它描述的是*你*正在构建什么。任务目标的意图、切片的规格、证明契约——任何供应商都无法预先替你编写这些内容；安装其他人的内容，会把陌生人的项目塞进你的智能体脑中。因此，拓扑树会随产品提供精选默认值（团队如何良好运行在很大程度上具有通用性），而项目树只提供此示例（你要构建什么，只属于你）。参见 `docs/reference/chain-file-convention.md`。

结构如下，每个层级只有一个链名称：

```
missions/<mission>/SPEC.md                   front matter 中的意图；切片所需的上下文
missions/<mission>/slices/<slice>/SPEC.md    唯一负责规定规格的层级
                                 .../PROGRESS.md  推导出的进度轨道
                                 .../PROOF.md     保留的证据：实际效果是否成立
```

真实项目可通过 `zrig scope mission create` / `zrig scope slice create` 创建这些脚手架——应优先使用工具，不要手工复制此文件夹。
