# 切片：01-shorten-first-run（完整示例）

## 意图

通过一条命令获得运行中的工作组；两分钟内看到第一个智能体。（切片是**唯一**负责规定规格的层级——UI 投影的就是这些准确的章节标题。）

## 最小需求

1. 在只运行过安装程序的机器上，`zrig up demo` 执行成功。
2. attach 提示将用户带入一个会向其问候的席位。

## 证明契约

- [ ] 一份干净机器首次运行的计时转录记录，从执行命令到看到智能体不超过两分钟。（每项承诺都要对应一项可观察产物——最容易漏掉、也最重要的检查正是“它真的有效吗”。）
