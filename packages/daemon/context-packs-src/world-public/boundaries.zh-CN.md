# 边界

## 此包涵盖的内容

<!-- world-claim: boundary-coverage -->
此公开包仅涵盖下列共享世界结构和发现界面。

- 世界、知识、Skill 与任务上下文之间的稳定分隔；
- 作为原子元数据的八个世界区域；
- “由作者提供”与“通过推导获得”的规则；
- 用于编写和检查世界的小型约定；
- 发现身份、拓扑、上下文包及命令帮助所需的实时命令。

## 此包不涵盖的内容

<!-- world-claim: boundary-exclusions -->
此公开包不提供特定工作组的现实情况、当前工作、本地知识、仓库说明或不可逆判断。

- 某个特定工作组的目的、参与者、拓扑、路径或当前状态；
- 你当前负责的任务目标；
- 某个席位或团队积累的本地知识；
- 特定工具的仓库说明；
- 不可逆的产品判断或操作者判断。

<!-- world-claim: boundary-guidance -->
这些空白并不是要用貌似合理的文字补齐的遗漏：应阅读本地世界、任务目标、知识、仓库说明和实时命令界面；若没有任何来源能够回答，再询问决策负责人。

## 命名空间边界

<!-- world-claim: private-ref-boundary -->
私有世界安装始终以各自的 ref 保留在工作组本地，绝不会被此内置包遮蔽。此包是 `world-public`。本地世界可以使用不同的 ref 并携带实例特有内容，无需继承这些公开字节，也不会被它们取代。
