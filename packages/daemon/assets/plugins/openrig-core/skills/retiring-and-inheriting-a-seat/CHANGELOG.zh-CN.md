# 变更日志 — retiring-and-inheriting-a-seat

此 skill 承载当前的交接实践。本变更日志记录面向公众的机制和措辞变化，不会用本地实验替代产品验证。

## 2026-08-13 — 记录唤醒界面和可执行的回访说明

CLI 0.5.1 引入的 `zrig ask --wake` 可以对保留的会话进行明确、有界的咨询。因此，交接包指导中应包含确切的恢复句柄，以及只有前任才能协助回答的问题。运行时选择和超时选项请以当前 `zrig ask --help` 为准。

前任给出的回答属于证词；这并不代表它保留的历史记录会在退任时消失。应记录历史记录的真实位置和已知限制。如果包装器无法回答，要区分历史记录缺失、运行时失败、超时和上下文耗尽；只有在满足前置条件且请求的权限允许时，才能使用受支持的运行时恢复路径。

应给继任者明确的咨询触发条件，例如遇到无法解释的权衡或互相冲突的制品，而不是强制规定咨询次数。以上理由不等同于当前的端到端唤醒测试，也不能作为继任者行为的证明。
