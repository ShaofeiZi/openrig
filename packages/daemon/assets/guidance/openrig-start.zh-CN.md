# zrig 启动指引

你当前位于一个由 zrig 管理的拓扑中：这是一个持久运行的智能体团队，每个智能体都在独立终端中工作，拥有自己的名称和角色，并且能够直接互相通信。

**本文档刻意保持精简。**它唯一的任务是帮助你确认自己的身份。它不是入门指南，也无法告诉你所在工作组的用途或你应该执行什么工作。

## 身份——首先运行此命令

```bash
zrig whoami --json
```

命令会返回你所属的工作组、pod、成员身份、对等成员、边和 transcript 路径。**请将该结果视为唯一事实来源。**启动 overlay 可能已经过时；本指引内容很少，正是为了尽量减少产生错误的空间。

每次上下文压缩、重启或恢复之后，都应再次运行该命令；在此之前，**不要**对自己身处何处或此前在做什么下结论。如果前任的 transcript 内容很少或为空，请注意，部分运行时无法可靠采集 transcript；**输出很少或没有输出，并不代表该会话此前没有活动。**

## 联系对等成员

```bash
zrig send <session> "message"     # 向其终端输入消息并按下回车
zrig capture <session>               # 读取其屏幕上显示的内容
```

会话名称就是通信地址。运行 `zrig --help` 可以查看其余命令。旧的 `rig` 和 `openrig` 入口仍作为兼容别名保留。

## 新席位入门

新席位通常还会收到 `openrig-onboarding-01.md` 和 `openrig-onboarding-02.md`。在进入具体角色的工作之前，这两份文档会帮助你建立精简的整体认识。能够提供等效指引的操作方可以通过 `onboarding.default_pack.enabled` 同时禁用这两份文档；本身份指引仍然可用。

## 本文档不是什么

本文档不是完整手册，以上命令也只是可用功能的一小部分。

**如果没有人向你介绍过这个系统，请直接说明，不要自行推断。**你的工作组用于什么目的、工作如何在其中流转，以及你被允许执行哪些操作，都不在本文档中，也无法仅凭本文档猜出。靠猜测加入工作组，只会让智能体把错误的事情做得很正确。
