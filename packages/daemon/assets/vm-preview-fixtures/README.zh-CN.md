# VM 预览夹具

供 Tart 预览环境使用的示例数据：一个 zrig 后台服务会加载具有代表性的内容，另一个保持空白，以便比较。

## 内容

- `workflows/` — 公开示例工作流规格。basic-loop 示例展示从接收到关闭的完整交接过程，不依赖私有工作组或机器。

## 使用方式

运行 `scripts/vm-bootstrap/two-daemon-start.sh`，然后将工作流 YAML 文件复制到已填充后台服务所配置的 `<workspace.specs_root>/workflows/` 目录中。后台服务会在下次列出工作流库时发现这些文件。

## 约定

- 包含用户名的路径统一使用 `/Users/example/...`。
- 使用 `<workspace.specs_root>` 等符号化配置路径，不要写死机器特定位置。
- 使用通用的逻辑角色和 ID，不要填写具体的会话、主机或工作组实例地址。
- 描述夹具所演示的产品行为；不要包含发布历史、内部所有权或实现计划。
